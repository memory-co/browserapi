# Set-of-Mark 的标注层铺进了活页面,人会看见

**状态**:**已修**(2026-08-21)—— 走的是下面第二条:**根本不在页面里画。**
**影响(修之前)**:每次 `observe`(默认 `annotate=True`)都会让正在看的人
闪一下框;DOM 模式下这次 mutation 还会被录进重放流。

## 现在怎么做的

[`observe.py`](../../../webmuxd/observe.py) 的 `_capture_annotated()`:

```
往页面里 appendChild 一层带编号的框 → Page.captureScreenshot → finally 里 remove
```

那一层是 `pointer-events:none`、`z-index` 拉满,而且在元素表抓完**之后**才铺
(否则它自己会被下一次快照当成页面内容)。`finally` 保证它不残留。

## 问题

**"不残留"不等于"没人看见"。** 画面是推的:

| 画面 | 后果 |
| --- | --- |
| JPG / VNC | 铺层那一刻页面变了 → screencast 推一帧带框的出去,**人看到一闪** |
| DOM | rrweb 把这次 DOM 变更录下来 → **观看端照样看到**,而且它是流里的一条 |

而 `annotate` 默认是 `True` —— 也就是**每一次 observe 都会闪**。

这和设计里那条是冲突的:观看者看到的应该是页面本身,
而不是我们为了给 agent 拍照临时加的东西。

## 该怎么修

**不在页面里画。** 干净截图 + 元素表(带 bbox)本来就都有了 ——
返回里同时有 `screenshot` 和 `plain_screenshot`,说明干净那张一直在。

于是有两条路,倾向第二条:

1. **服务端在图上画** —— 拍完干净图,把框画到位图上。页面完全不变。
   代价是服务端要能画图
2. **根本不画,把 bbox 给出去** —— agent 要的是坐标,不是画好的图;
   真需要 SoM 图喂多模态模型的场景,调用方拿 bbox 自己叠。
   **这条最干净:少一个功能,少一类 bug**

无论走哪条,`annotate` 那个默认值都该重新想 ——
一个会改变页面、会被别人看见的行为,不该是默认开的。

## 修了什么

选了第二条,而且**连那个参数一起去掉**,不是把默认值改成 `False`:

- `observe()` 不再有 `annotate`,`_MARK_JS` / `_capture_annotated` 整段删掉
- `Observation` 只剩**一张图**:`plain_screenshot` / `plain_url` /
  `?annotate=false` 一起没了 —— 标注不进页面之后,"干净版"和它就是同一张,
  **两个名字指一件事**正是这个项目不许的
- 叠 Set-of-Mark 要的东西一次都在:编号 `elements[].id`,位置 `elements[].bbox`

**为什么不选第一条(服务端在图上画)。** 截图是 WebP,要画就得
解码→画→再编码,那意味着 Pillow 变成硬依赖 —— 这个包今天只有
`websockets` 和 `aiohttp` 两个,为一个调试用的便利加一个图像库不划算。

**为什么"先停画面再画"不成立。** 想过:JPG 那条确实可以
`stopScreencast → 铺 → 拍 → 撤 → startScreencast`。但 **VNC 那条不行** ——
xpra 盯着 X 显示连续编码,停不下来;**DOM 那条更不行** ——
rrweb 录的是 mutation,铺一层就是一条事件,进流里就撤不掉了。
**页面不能变,只能是页面不变。**

## 量出来的

拿 DOM 那条流直接看 —— 静止页面上连着观察,期间调三次 `observe`:

```
修之前 : 观看端收到 6 条事件,**其中 3 条带 __webmuxd_marks**
修之后 : 观看端收到 0 条
```

三次 observe,三条标注层的 mutation 原样推给了正在看的人 ——
而且它们**留在重放流里撤不掉**:后连上来的观看者重放到那儿,框还会再闪一遍。

## 守它的那条测试

`tests/doing_and_seeing/test_观测不许改页面` ——
验的不是"撤干净了",是**观测前后 DOM 指纹一模一样**。
这个区别就是这条 issue 本身:`finally` 保证不残留,保证不了没人看见。

## 顺带记一条

`locate.py` 本身**不碰页面**,编号只存在于返回的 JSON 里 ——
这一条是对的,不要一起改掉。有问题的只有 `observe.py` 里那个铺层的动作。
