# who_is_in_front —— 浏览器把哪一页放在前台

tab 表里的每一样都来自浏览器自己的 target 表:开、关、url、title,
全是 CDP 推过来的。**只有一样不是** ——

> `active`(当前是哪个 tab)。CDP 根本没有「tab 被激活了」这种事件。

所以那个字段一直是我们单方面记的一本账,改完用 `Target.activateTarget`
把浏览器拽过来对齐。这套做法有一个没写出来的前提:

> **只有我们会动前台。**

不是的。

## 那个前提怎么塌的

页面 `window.open` / `<a target=_blank>` 开出来的 tab,
**Chromium 直接把前台切过去,而且不发任何事件**。实测(Chromium 152):

| 问谁 | 新那个 tab | 原来那个 |
| --- | --- | --- |
| `document.visibilityState` | `visible` | **`hidden`** |
| `document.hasFocus()` | `true` | `false` |
| 我们那张表的 `active` | 不是它 | **还是它** |

于是「焦点不跟过去」这条规矩变成一句只写在我们字段里的空话。
两条腿各错各的,**都不报错**:

- **VNC**:画面是那个真窗口,人看到的是**新那一页**,而 tab 条高亮、
  地址栏、不带下标的命令**全指着旧那一页**。用户就是这么发现的。
- **JPG**:截屏还挂在旧 target 上,后台不产帧 —— 画面**冻在旧那页最后一帧**。
  看着一致,其实已经死了。

`docs/v2/works/f-tabs.md` §3 原来写着「漂移在物理上不可能:真漂了就是黑屏,
立刻可见」。**那句话错了**,而且错在把"没有新帧"当成了"没有画面" ——
没有新帧的结果是上一帧留在那儿,那恰恰是最不容易被发现的一种坏。

## 结论:让浏览器说了算,一个例外都没有

> **`active` 就是"浏览器现在把哪一页放在前台"。
> 我们的命令只是发个信号,要等那一页自己报回来才算数。**

理由不是省事,是**浏览器判得比我们好**。同一个 `target=_blank` 链接:

| 怎么点 | Chromium |
| --- | --- |
| 普通左键 | **前台开** |
| Ctrl + 左键 | **后台开** |
| 中键 | **后台开** |

而我们那条输入腿本来就把 `modifiers` 和 `button` 原样转给了 CDP。
人的意图靠手势表达,Chromium 解释它 —— 我们自己再定一套"跟不跟",
第一件事就是把 Ctrl+左键判错。
(那三种点法的用例在 [`v2_browser_new_tab`](../v2_browser_new_tab/),
因为它要走完整条输入腿。)

## 这儿验三条

| | 验什么 |
| --- | --- |
| `浏览器把前台给谁_我们就跟谁` | 页面自己开了个前台 tab,`active` 跟过去 |
| `我们发的切换_返回的时候已经是真的了` | `activate()` **返回即为真** —— 一返回就问那一页,不轮询、不给余量 |
| `别人把前台抢走_我们跟着走` | 第三方 `activateTarget`,我们这边没有任何代码"知道"它发生过 |

中间那条是最硬的:原来 `activate()` 先改 `self._active` 再发命令,
所以它返回得更早,**而且返回的时候那件事可能根本没发生**。

## 判据一律来自页面那一侧

`document.visibilityState`,经**第二条 CDP 连接**读回来 ——
和我们那张表没有任何关系。

这一条是这个目录存在的理由。原来 `v2_browser_new_tab` 里那四条断言
(bar 高亮、地址栏、后端 `active`、不带下标的命令)**全都源自同一张表**:
一份账抄四遍,再怎么对账也对不出问题,它们一起漂的时候一条都不会红。

## 两个用得上的事实

**一、`chromium_endpoint` 是 session 级的。** 整个测试跑共用一个浏览器,
所以 `live` 先把残留的 page target 清干净 —— 别的用例留下来的 tab 会
直接把"前台是谁"这个问题搅浑。(单跑绿、跑全量红,就是这么来的。)

**二、探针现在是一进表就装的。** 原来注入发生在 `executor_for()`,那是懒的,
于是页面自己开的那个 tab 在被人碰之前是**哑的**(`window.__wm_side`
是 `undefined`)—— 而那恰恰是最常见的那种前台变化。改成 adopt 就装之后,
每个 tab 都说得出话。
