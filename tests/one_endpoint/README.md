# one_endpoint — runtime 只做一件事:给出一个 CDP 端点

## 这个场景在测什么

v2 的契约只剩一条(**一个 CDP 端点**,[docs/v2/works/07](../../docs/v2/works/07-runtime.md)),
所以这个场景比 v1 的 `two_endpoints` 短了一多半。锁的是:

1. **只有两种 runtime,默认是本机起一个。** 容器不在里面 —— 而且敲 `container`
   要能得到一句指向 works/07 §2 的话,因为从 v1 升上来的人第一件事就是敲它。
2. **不降级。** 指定的浏览器不在就抛,并说去跑 `webmuxd install` ——
   随便挑一个等于让你以为在跑钉死的那一版。
3. **版本是钉死的。** `tests/chrome_facts/` 那句"换大版本先跑它"要能执行,
   前提是版本确定;换源只换前缀,不换版本。
4. **`remote` 的 `stop` 不动对面。**
5. **端口被占了就说被占了**,不替你换一个。
6. **一个 session 一个口**:`Handle` 只有 `port`,`view_url` 和 `api_url`
   落在同一个上,而且 v1 那个"没有画面就是空字符串"的分支不存在了。
7. **v1 的参数名不静默吞掉**(`api_port=` / `view_port=` / `image=` / `network=`)——
   落进 `**kw` 被丢掉最糟:报出来的错会指向别处。

真起真跑那一条会把浏览器 + sessiond 拉起来,**然后 `urlopen` 那个口的根**,
确认画面页真的在那儿 —— 不是只看 API 通不通。

## 不在这测什么

- **帧和输入** —— 在 [`pixels_on_a_wire/`](../pixels_on_a_wire/)。
  这里只验"那个口上有画面页",不验画面本身。
- **记录怎么读怎么写** —— 在 [`installing/`](../installing/)。
- **下载本身** —— 那要网络,而且它是 `urllib` 的事。这里只验 URL 怎么拼。

## v1 那 600 行去哪了

大半是在验"容器命令怎么拼、镜像标签怎么读、host 网络下怎么绑" ——
而那整套机制存在的理由是**描述别人的镜像长什么样**。v2 没有别人的镜像了,
所以它们跟着 `runtime/container.py` 一起删了。git 历史里还在。
