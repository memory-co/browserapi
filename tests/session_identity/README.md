# session_identity — id 说了算,端口你给

## 这个场景在测什么

lib 是主体,这个场景测的就是三个对象(`Webmuxd` / `Session` / `Tab`)的语义:

1. **`Webmuxd()` 是空壳** —— 构造它不起容器、不占端口、不跑浏览器。
2. **`session(id=...)` 幂等**,同一个 id 返回**同一个 Python 对象** ——
   给两个就是两条 WS、两份可能不一致的表。
3. **端口必须你给**,不自动分配。
4. **属性读内存,不发请求。** `tab.url` 读的是那份被事件推着更新的表 ——
   这是"人和程序看同一块"的实现方式。
5. **`act()` 不抛,快捷方法抛。** 写 agent 循环时要把候选喂回模型自我纠正,
   而不是被异常打断。
6. **tab 关掉之后属性还能读**(最后的值),但动作要拒绝 —— 回看和操作是两回事。

## 不在这测什么

- HTTP 那层的线上格式 —— 在 [`the_http_face/`](../the_http_face/)。
- 定位规则 —— 在 [`pointing_at_things/`](../pointing_at_things/)。
