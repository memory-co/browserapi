# the_scrollback — 日志就是 scrollback

## 这个场景在测什么

日志不是给机器对账的事件流,是**给人和模型回看的**。这个场景锁的是这句话的后果:

1. **类目是封闭的**(v1 三类 + v2 那五类原生 UI),多一类要报错 ——
   类别一多,"读某个 tab 的日志"就得先学一套分类法。
2. **一个 jsonl 文件,按条数切一刀**,像 tmux 的 `history-limit`;
   切掉的记录对应的截图也要一起清,不留孤儿文件。
3. **`seq` 单调且共享**,重启之后接着数 —— 它是"这之后发生了什么"的锚点。
4. **半行不能毁掉整份日志。** 进程被杀在写一半是常态。
5. **打包能带走**,离线可读,而且页面内容要转义(日志里混着别人的 HTML)。

## 不在这测什么

- 事件流(WS)推什么 —— 那是内存里的东西,在 [`the_http_face/`](../the_http_face/)。
- CLI 怎么把日志显示出来 —— 在 [`cli_shell/`](../cli_shell/)。
