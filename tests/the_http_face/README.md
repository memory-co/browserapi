# the_http_face — HTTP 面存在的唯一理由是可独立验证

## 这个场景在测什么

API 不是给外部当产品用的,它存在是为了让 webmuxd **能作为独立模块被验证** ——
不依赖任何上层,就能证明这个模块自己是对的。这个场景就是那份验证:

1. 路由、请求体、响应形状,和 lib 的语义一一对上。
2. **API 不做 lib 没有的事。**
3. 动作是串行的、遇错即停;一个 session 同时只处理一个动作(忙就 409,不排队)。
4. 事件流(WS)是内存里的东西,断线要能补,补不齐要先说 `gap`。

## 不在这测什么

- lib 那边的便利(`with`、下标、按标题找 tab)—— 那些**故意不导出**,
  🔲 没有地方在验了(`session_identity/` 删了)。
