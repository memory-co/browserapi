# installing — 装一次,之后别再问

## 这个场景在测什么

`webmuxd install` 只回答两个问题:**docker 能用吗、这个网络环境拉得到镜像吗**。

1. **没有记录也照常能用** —— 它省的是重复开销,不是"必须先装"。
2. **不 build、不预拉。** 探测不该顺手做一件 4 GB 的事。
3. **拉不到就不写那个键。** 记一个拉不下来的名字,等于骗后面的自己。
4. **配置不得改变库的行为**:记录里只有机器的事实,传进来的永远赢。
5. **记录会撒谎** —— 按它去起、起不来就报错并让人重跑,不静默重探。

## 不在这测什么

- runtime 起容器的命令怎么拼 —— 在 [`two_endpoints/`](../two_endpoints/)。
