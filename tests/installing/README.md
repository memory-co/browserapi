# installing — 装一次,之后别再问

## 这个场景在测什么

v1 的 `webmuxd install` 问的是"docker 能用吗、拉得到镜像吗"。
**v2 换了另外两个问题**([docs/v2/works/07 §4.4](../../docs/v2/works/07-runtime.md)):

> **这个网络环境下得到那个浏览器吗、系统依赖齐吗。**

docker 那一问整个消失 —— v2 不再关心机器上有没有它。

**但记录的规矩一条没改**,所以这里大半的用例是原样留下来的:

1. **没有记录也照常能用** —— 它省的是重复开销,不是"必须先装"。
2. **幂等。**"检查"和"安装"是同一个命令,已经下过就跳过,不重下。
3. **下不到就不写那个键**,并且**把国内那个源说出来** ——
   记一个下不到的路径,等于骗后面的自己。
4. **它不是配置文件**:记的是机器的事实,传进来的永远赢。
5. **记录会撒谎** —— 你 `rm -rf` 了缓存目录它不知道,所以按它去起、
   起不来就报错**并让人重跑 install**,不静默重探。
6. **缺共享库和缺中文字体都要明说。** 以前镜像替用户扛掉了这些,
   现在落到裸机上 —— 撞上"中文全是豆腐块"的人一定会以为是 bug。

## 不在这测什么

- **下载本身** —— 那要网络,而且它是 `urllib` 的事。URL 怎么拼在
  [`one_endpoint/`](../one_endpoint/)。
- **浏览器起来之后干了什么** —— 在 [`one_endpoint/`](../one_endpoint/) 和
  [`pixels_on_a_wire/`](../pixels_on_a_wire/)。

## fixture

`fake_download` 把 `browser.install` / `find` / `find_system` / `missing_libs` /
`has_cjk_font` 全换成可控的假货 —— **这个场景测的是 install 的决策,
不是它下载的本事**。
