# pointing_at_things — 按人看得见的字找东西

## 这个场景在测什么

不用写选择器,是这东西对调用方最大的承诺。这个场景锁的是"找"的全部规则:

1. **分档匹配**:精确 → 子串 → 忽略大小写,**命中一档就停**。
2. **有歧义不替你挑。** 匹配到多个就报 `not_found` 并把候选全给出来 ——
   替调用方挑一个,错了他永远不知道为什么。
3. **`nth` 是消歧的正当出口**,越界要说清一共有几个。
4. **找不到也要给候选**:`candidates` 永不为 `None`,哪怕一个都没匹配上,
   也得告诉调用方这页上有什么。
5. **`label` 只匹配能往里打字的东西** —— 不然 `type()` 会打到一个标题上。
6. **禁用的元素是"点不了"不是"找不到"** —— 两种情况该做的事完全不同。

## 不在这测什么

- 点下去之后发生了什么 —— 在 [`doing_and_seeing/`](../doing_and_seeing/)。
- 定位失败在 CLI 上长什么样(退出码 4、列候选)—— 在
  [`v2_cli_simple/`](../v2_cli_simple/)。
