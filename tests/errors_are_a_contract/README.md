# errors_are_a_contract — 错误分类指向不同的下一步

## 这个场景在测什么

错误不是给人看的字符串,是**调用方据以决定下一步**的东西:改代码 / 重试 / 报警。

1. **每个线上 code 都有一个类**,而且三类分法(用法错 / 可自愈 / 平台级)成立。
2. **不认识的 code 按 HTTP 状态兜底**,而不是 `KeyError` —— 服务端加了新码,
   老客户端不该崩。
3. **半个响应体也要能变成异常** —— 网络中断时拿到的就是这种东西。
4. 定位失败要带候选,`tab_gone` 要分得清 `closed` 和 `evicted`。

## 不在这测什么

- 具体某个动作什么时候报什么 —— 在各自场景里。
