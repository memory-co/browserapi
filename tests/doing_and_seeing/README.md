# doing_and_seeing — 做一下,然后看看变成什么样

## 这个场景在测什么

动作和观测是同一件事的两半:做完要能说出**发生了什么**,不然调用方只能自己截图去猜。

1. **变化要变成一句人话**:弹出的提示、新出现的文字块、消失的表单,
   都要能被描述出来;**什么都没变就什么都不说**(而不是编一句)。
2. 太长的文本要截断 —— 它是给人和模型看的一句话,不是页面转储。
3. **观测一次给全**:元素表 + 标注截图 + 纯截图 + 盲区提示(`notes`)。
4. **标注层是临时的**:画上去、截完就撤,不能留在页面上污染下一次观测。

## 不在这测什么

- 元素怎么被找到的 —— 在 [`pointing_at_things/`](../pointing_at_things/)。
- `act` 在 HTTP 上的请求/响应形状 —— 在 [`the_http_face/`](../the_http_face/)。
