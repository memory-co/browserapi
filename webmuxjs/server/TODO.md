# JS 版服务端 —— 今天不实现

留这个目录不是占坑,是**给协议一个不属于任何语言的家**。

今天服务端只有 Python 一份([`webmuxd/`](../../webmuxd/))。
真要写 JS 版的话,它要实现的就是 [`protocol/`](protocol/) 里那几篇 ——
**照文档实现,而不是照着 Python 代码翻译**。这两件事的区别是:
前者会逼出"文档里没写清楚的地方",后者只会把 Python 的偶然选择也抄过去。

## 什么时候才值得做

一条:**有人要把 webmuxd 嵌进一个已经是 Node 的进程里。**
在那之前,多一份实现只是多一份要同步的东西。

而"同步得住"这件事本身有办法 —— `client/fixtures/` 那套对拍
([j §4.2](../../docs/v2/works/j-layout.md#42-和-python-对拍))
就是为两份实现准备的:给定输入 → 期望的字节,谁改了格式两边一起红。
